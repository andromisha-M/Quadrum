  • Row 1 frozen — headers stay visible however far down you scroll.
  • C and D formatted as numbers with two decimals and thousands grouping, so they display as 1,200,000.00 while staying summable.
  • K1 label, K2 value — the total sits clear of the data so adding rows never disturbs it. Row 1 is the header row, so the number itself lands in K2.
  • Banded rows and generous column widths for long Serbian company names.
  • F carries the project name read off the invoice, so one sheet can hold several campaigns and still be filtered per project.
The catch: none of this styling survives today's setup. n8n's Convert to File writes bare values, and the whole file is rewritten after every invoice — so bold headers, widths, colours and number formats are wiped each run. Formatting only sticks if we append rows to a Google Sheet you've styled once, instead of regenerating an .xlsx. That swap is about six nodes.
